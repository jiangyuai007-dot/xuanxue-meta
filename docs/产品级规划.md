# 玄机 · 产品级 UI 与功能总体规划

> 定位一句话：**给普通人用的专业级东方命理排盘与解读工具**——排盘专业到经得起同行检验，解读通俗到普通人读得进去，付费买到的是「深度内容」而不是「解锁动画」。
>
> 版本：2026-09-30 · 作者：架构师/PM

## 一、产品骨架（信息架构）

```
玄机（单机优先，账号留接口）
├── 四大体系（各自独立页，共享同一套框架与设计系统）
│   ├── 八字命盘   排盘 → 命书十章（免费2章引流 + 付费8章）
│   ├── 六爻占卜   六种起卦方式 → 卦象 + 3 付费章
│   ├── 奇门遁甲   时家排盘 → 九宫盘 + 3 付费章
│   └── 紫微斗数   排盘 → 十二宫盘 + 4 付费章
├── 我的档案       排盘参数本地留存（20 个），一键重排
├── 我的已购       订单/已解锁章节清单 + 重新阅读
└── 报告导出       报告页（HTML）/ 分享卡（SVG 朋友圈图）
```

**单机产品形态是刻意的**：无登录、无多用户，已购记录持久化在本机 localStorage（数据结构预留 orderId/factPackId，将来接账号即可云同步）。先做好「打开即用、付了就在」，不背账号体系的复杂度。

## 二、设计系统（已落地，docs 同步）

**气质：中式纸墨 + 现代排版。** 不是复古仿古，是「宣纸底 + 墨字 + 金色点睛」的现代编辑排版。

| Token | 值 | 用途 |
|---|---|---|
| 纸面 | `--paper:#f6f1e6` / 卡面 `#fffdf8` | 页面底/卡片，径向暖晕提升纸感 |
| 墨 | `--ink:#2f2a22` / `--ink-2:#6b5640` / `--sub:#8b8172` | 三级文字 |
| 金 | `#b0812b` / `#c9a961` / 深金 `#9a7720` | 主按钮、选中态、价格、章节序号 |
| 语义色 | 朱 `#b3392c`（动/凶）、竹绿 `#2f7d52`（吉/成） | 命理语义色，**不许挪作 UI 装饰** |
| 圆角 | 8 / 12 / 16px 三级 | 控件/卡/大卡 |
| 阴影 | 两级，暖灰调 | 悬浮微抬升，不做重投影 |
| 字号 | 11 / 12.5 / 14 / 17 / 22px 五级 | 标签/辅文/正文/小标/标题 |
| 字体 | Noto Serif SC（干支与标题）+ PingFang SC | 干支必须有衬线的仪式感 |

**框架三件套（四页像素级一致）**：墨金顶栏 + 分段式 tab + 三级按钮（金色主按钮 / 描边次按钮 / 虚线弱按钮）。
**命理色语义铁律**：五行色、六神色、门星神色是**内容语义**，任何视觉统一不得覆盖它们。

## 三、排盘图标准（「像产品」的关键）

排盘图是产品的脸面，验收标准从「能看」升级为：

1. **像素级对齐**：多栏并列的卦/宫，同行元素坐标差 ≤1px（CDP 实测，进 audit 工具）。
2. **固定结构**：行高/宫高恒定（height 锁死），徽标绝对定位不占布局流，任何数据组合不改变骨架。
3. **密度即专业**：专家一眼能核的信息（纳甲、藏干、长生、空亡、神煞）必须在场且可悬停溯源；但默认视觉只突出三件事——**世应、动爻、用神**。
4. **可解释**：每个符号都可点/悬停出白话解释 + 依据出处（古籍/口诀），这是与「截图糊弄」产品的分水岭。
5. **响应式三档**：≥1280 全景；375 单列重排（卦图纵排、九宫缩字不缩信息）；360 不破版。

## 四、内容标准（付费的底气）

**免费章节**（命局总论/格局用神、卦象/世应）：足以核验排盘准确性 + 建立信任。
**付费章节**的出厂标准：
- 每章 ≥600 字，推理链写作：某干支 → 落某宫 → 主某事 → 结合喜忌定调 → 给应对；
- 全部数据绑定真实盘面，禁止模板套话（「形成3项作用」这类句子一票否决）；
- 术语零损坏（合规网关不吞「空亡」「不必」），依据溯源可核验；
- 锁定章展示**真实正文前 120 字**作为钩子 + 字数标注——用户看到的就是会买到的。

## 五、商业化闭环（已实现）

```
锁定章卡片（钩子+字数+价格）
  → 支付弹层（章节清单 → 合计 → 确认）
  → 订单落盘（data/orders.json，状态机 pending/paid/refunded）
  → 本机已购持久化（localStorage，按体系×章节键）
  → 解锁即读，刷新/重开浏览器不丢
  → 「我的已购」随时回看
```
单章 ¥0.99–9.9 差异定价（称骨 0.99 引流、大运流年 9.9 压轴）、完整报告 ¥19.9、报告+追问 ¥29.9、月卡 ¥19.9。追问（LLM 问答）是唯一的真 API 成本项，**放在最高价 SKU，绝不免费化**。
