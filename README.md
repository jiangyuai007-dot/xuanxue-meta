# 命理内容产品原型（mingli-app）

一个**可实际运行**的命理内容产品原型：确定性排盘引擎 + 本地解读引擎 + 合规网关 + 报告渲染 + Web 界面。
零第三方依赖、零网络调用，离线可跑、结果可复现。

> 完整设计说明见 [`docs/架构设计.md`](docs/架构设计.md)

---

## 1. 快速开始

```bash
# 进入项目目录
cd E:\WorkBuddy\xuanxue-meta

# 安装依赖：无（零依赖）
# 启动服务
node src/server/index.js

# 浏览器打开
http://127.0.0.1:8787
```

可换端口：`PORT=9000 node src/server/index.js`

### 在本机持久运行（推荐）

WorkBuddy 沙箱会在会话空闲/重连时回收所有衍生进程，因此**不要**依赖本工具内启动的服务长期在线。
请在**你自己的系统终端**（CMD / PowerShell，不经过 WorkBuddy）里运行，这样才能一直开着：

```bat
cd /d E:\WorkBuddy\xuanxue-meta
node src/server/index.js
rem 浏览器打开 http://127.0.0.1:8787
```

### 在 WorkBuddy 内临时查看

若只想在当前活跃会话里看一眼，可在对话中让我执行后台启动；会话结束后服务会被自动回收。
脚本 `scripts/start.js` 仅在"单次工具调用内"负责脱离启动并打印结果，不保证跨会话存活。

若端口被占用（旧进程残留）先释放：
```bat
netstat -ano | findstr :8787
taskkill /PID <PID> /F
```

1. 打开 `http://127.0.0.1:8787`
2. 八字页输入 `1990-05-20 14:30 北京 男` → 点「排盘」→ 应看到 `庚午 辛巳 乙酉 癸未`

6. 切到「奇门」→ 选事由 → 生成报告 → 看到九宫图与方位建议

## 7. 已知限制

1. **紫微斗数火星/铃星为近似**：命宫/身宫、五行局、紫微/天府、十四主星、四化、辅星、大限均按本派通用标准（已与公开权威资料核对 + 二十项不变量校验）；唯独火星/铃星按中州派近似规则安放，引擎 `meta.approximations` 已标注为待校验项。
2. **天文算法存在分钟级误差**：太阳视黄经误差约 ±0.01°（≈±15 分钟），朔时刻误差约 ±10 分钟。仅影响恰好出生在节气/朔交界 15 分钟内的极端个案，已在事实包 `meta.warnings` 中提示。
3. **时区简化**：1900 年后中国境内统一按 UTC+8。
4. **无真实支付、无账号体系**：订单为本地模拟 JSON；档案用浏览器缓存。
5. **解读为规则模板生成**：文学性弱于大模型，但可复现、无幻觉。配置 `LLM_ENDPOINT` / `LLM_API_KEY` / `LLM_MODEL` 后可切换大模型（兼容 OpenAI `/chat/completions` 协议），失败自动回落本地。
6. **性能未做规模化优化**：缓存为进程内存 + 文件级，非分布式。
